Cette page permet de demander la suppression des données liées à Mathéquête sans réinstaller l'application. Vous pouvez aussi écrire directement à coresrdi@gmail.com. Cette page ne nécessite pas de compte ni d'installation du jeu.

1. Comment faire la demande

  1. Sur l'appareil (facultatif, immédiat) : dans Mathéquête, un parent peut supprimer le profil de l'enfant (gestion des profils) ou désinstaller l'application. Cela efface les fichiers locaux, pas les données déjà envoyées à nos serveurs, à Stripe ou à Google.
  2. Pour les données chez nous ou chez un partenaire : remplissez le formulaire ci-dessous, ou envoyez un courriel à coresrdi@gmail.com avec les mêmes informations. Le formulaire ouvre votre application de courriel avec un message déjà structuré ; vous relisez et envoyez.
  3. Nous traitons la demande dans les meilleurs délais, et au plus tard dans le délai prévu par la loi applicable (au Québec, typiquement 30 jours).
  4. Dans le jeu (à partir de la version qui suivra le paquet Play versionCode 37), le bouton Supprimer mes données de l'Espace parent (Réglages) ouvre cette page, après une porte parentale.

2. Quelles données sont supprimées ou conservées

Mathéquête ne crée pas de compte enfant avec mot de passe. Selon ce qui existe réellement pour vous, une demande peut viser :

  • Supprimées sur demande : les activations de licence liées à votre appareil ou à votre courriel, l'empreinte d'appareil associée, les demandes d'activation manuelle, et les identifiants école que le jeu aurait envoyés au moment de l'enregistrement (prénom, et le cas échéant nom, niveau, code de classe).
  • Sur l'appareil : à supprimer par vous (profil ou désinstallation). Nous n'avons pas accès à ces fichiers à distance.
  • Sauvegarde Google Play Jeux : nous pouvons vous aider à cesser les envois. Les copies déjà chez Google se gèrent depuis le compte Google (ou avec notre aide). Les désactiver dans Réglages n'efface pas automatiquement la copie chez Google.
  • Compte enseignant (application distincte Mathéquête Prof) : un enseignant peut supprimer son propre compte depuis cette application. Côté serveur, cette action appelle DELETE /api/prof/me/delete. Un enseignant peut aussi utiliser le formulaire ci-dessous.
  • Conservées le temps exigé par la loi : les factures et justificatifs d'achat (Stripe ou Google Play), typiquement plusieurs années pour les obligations comptables (Revenu Québec / Agence du revenu du Canada). Elles ne seront plus utilisées à d'autres fins.
  • Journaux techniques (vérification de version, traces d'infrastructure, éventuellement une adresse IP vue par Cloudflare) : ils expirent selon les pratiques habituelles de l'hébergeur et nos besoins de sécurité. Nous ne promettons pas un délai plus précis ici.

Le jeu n'envoie pas périodiquement les statistiques de progression vers un serveur ou vers l'application prof. S'il n'existe pas de données serveur à votre nom, nous vous le dirons.

3. Formulaire de demande

Aucun renseignement n'est envoyé à un serveur par cette page : le message est préparé dans votre courriel, vers coresrdi@gmail.com.
