Summary: Mathéquête is an educational game for children that mostly runs on the device. Some network calls happen automatically (license and version checks). Others happen only if a parent or guardian takes an action (activation, purchase, school identifier, Play Games cloud save, support email). No targeted advertising, no marketing profiling.

1. Who we are

Mathéquête is developed by Jeff Gravel, an independent developer based in Quebec, Canada, under the CORES RDI (coresrdi) brand. This document describes the privacy practices of the Mathéquête app distributed on Google Play as com.coresrdi.mathequete, of builds outside Play (Windows and others), of the website mathequete.pages.dev, and of the API at https://api.mathequete.com (Cloudflare Workers).

Under Quebec's Law 25, Jeff Gravel is the person in charge of the protection of personal information. For questions, access, correction or deletion: coresrdi@gmail.com, or the data deletion request page.

2. Audience — a children's app

Mathéquête is designed for school-age children, typically ages 4 to 12. We aim to comply with:

  • the U.S. Children's Online Privacy Protection Act (COPPA);
  • the EU General Data Protection Regulation (GDPR), including rules for minors;
  • Quebec's Law 25 on personal information in the private sector;
  • Google Play's Families Policy.

We do not intentionally send a child's personal information off the device unless a parent or guardian has triggered the relevant action (for example a school identifier, an email activation request, a purchase, or a Play Games cloud save). If you believe data was sent without your agreement, write to coresrdi@gmail.com. We will handle deletion requests promptly and within any deadline required by applicable law.

As a result: no targeted advertising, no advertising identifier, no advertising-analytics SDK, no sharing for marketing.

3. Data stored on the device

By default, progress and profiles stay on the device. The app stores, among other things, in local files (often JSON):

  • profiles (display name, colour, progress, inventory, gameplay preferences);
  • optional civil identity (first name, family name, year of birth) and an identifier derived by hashing those fields, intended to help a teacher recognise the same student — these remain local unless reused in a transfer described below;
  • an optional school identifier (teacher name, class code or number, and sometimes student name, level, short code, QR key);
  • local gameplay statistics, the Histoquête journal, audio settings, the school-sync mode setting, a license cache, a technical device key, and a management PIN (stored as a salted hash, not in plain text);
  • purchase status and license codes, which can be checked offline with an HMAC-SHA256 signature.

On-device encryption: the PIN is hashed. An AES-256-CBC with HMAC module exists in the app, but profiles and most save files are stored as unencrypted JSON in the app's private storage. Anyone with access to those files (for example on an unlocked device) could read them. You can delete a profile in “Manage profiles”, or uninstall the app to erase local data.

4. Network communications — what the game actually does

The game talks to https://api.mathequete.com (Cloudflare). The former host mathequete-api.coresrdi.workers.dev is no longer used by the game. All of the game's requests to that server use HTTPS.

Two distinct technical device identifiers may be sent, depending on the feature: a fingerprint (SHA-256 of an install identifier, with an app-specific salt) and a device_hash (SHA-256 of the install identifier). These are not an IMEI, a phone number, or the Android advertising ID. They link a license or an activation request to the device.

4.1 Automatic communications

  • Version check (about every 24 hours if the default setting is left on): the game sends the installed version, the platform name (e.g. Android, Windows) and the device fingerprint, to see whether an update is available. On the server this is logged; we did not find it being stored in the license database.
  • Licenses on this device: a few seconds after launch, and when the profile changes, the game queries the server with the fingerprint to refresh active products (and offline grace periods). No other profile data is attached to that call.

Without Internet, the game remains playable with local progress; some online licenses may eventually require a reconnection after a long time offline.

4.2 License activation, transfer and release (user-initiated)

When you scan or enter a QR code, or release a license to change devices, the game may send:

  • the license key or code;
  • the device fingerprint or device_hash;
  • optionally a student nickname, a product identifier, or a masked key for transfer tracking.

The server records the activation so that the number of devices per code can be limited. You can remove the license from this device in the game's license screen.

4.3 Manual activation by email (adult-initiated)

If you request a manual activation, the game sends the relevant code, your email address, an optional name, an optional message, and the device_hash. It then periodically checks the server (request and device identifiers) until approval, refusal or expiry. License emails for a website purchase are sent through Resend by the server, not directly by the app.

4.4 School identifier (opt-in, when the school profile is saved)

If a school identifier is entered in the profile (in practice from the management area, protected by a parent PIN when one is set), the game may:

  • ask the server for public information about a QR code (product, class code if any, class label) — without exposing the teacher's email;
  • when saving, send the class code, first name, and optionally last name, level and a short student code, together with the QR key.

What the game does not do today: even though a local setting exists for an “automatic / ask first / manual” teacher-stats sync, we did not find, in the game's code, a periodic upload of progress statistics to the server or to the teacher app. Those modes are stored on the device only. The separate Mathéquête Prof app for teachers can manage encrypted student records and a teacher account; that does not mean the game already pushes the child's stats. If that feature is added later, this policy will be updated before or together with the release.

4.5 Optional Google Play Games cloud save (Android, parent opt-in)

Games are always saved locally. An Android cloud save via Google Play Games is offered in Settings (parent area).

Starting with the next Play package (versionCode greater than 37, in practice 38 or later): Play Games is no longer signed in at startup. A parent must turn it on, behind a parental gate (a two-digit multiplication, or a number written in words to be typed in digits; after three failures, a short lockout). The game works without a Google account. This is the behaviour of the code now published on the game's main branch.

Versions currently in internal testing or already distributed, versionCode 36 and 37 (package 37 is named “beta 3.7”): these versions still attempt a Play Games connection at Android startup. That behaviour will stop only once the next package (versionCode > 37) is installed.

If a parent enables cloud save:

  • Google may ask them to choose or confirm a Play Games account (a supervised account where applicable);
  • the app may receive a Play Games player ID and store a copy of progress (profile, scores, inventory, preferences) in Google Play Games cloud saves for that account;
  • turning the option off stops future uploads; it does not automatically delete copies already stored with Google, nor local saves.

CORES RDI does not use this save for advertising. Google's rules also apply: policies.google.com/privacy.

4.6 Histoquête media

Some Histoquête stills and audio tracks are downloaded from https://mathequete.pages.dev/videos/histo/ (Cloudflare Pages) and may be cached on the device. No profile data is attached to those downloads.

4.7 Bug reports and suggestions

“Report a bug” and “Make a suggestion” do not post to our servers directly. They open the device's email app to coresrdi@gmail.com, with a draft containing the game version, platform, system language, date, and a short 8-character identifier (a hash of a profile or device id). The child's name, age and email are not inserted by the game. Opening the email is preceded by a parental gate (starting with the next package, versionCode > 37). The parent can edit or delete the draft before sending.

4.8 External links

The game may open, in a browser or system app: this privacy policy, the data deletion request page, the storefront mathequete.pages.dev, a Stripe payment page, or the store listing. Starting with the next package (versionCode > 37), every outgoing link, every purchase (Google Play or Stripe) and every purchase restore is preceded by the parental gate.

5. Android permissions

According to the published Android package (AAB 37), the app requests:

  • INTERNET and ACCESS_NETWORK_STATE — the communications in section 4 and purchases;
  • CAMERA — only to scan a license or school QR code, when the user starts the scanner, not at launch. No photo is saved or uploaded. Only the text read from the QR may then be sent to the server if you activate the code. The camera is optional (manual entry works without it);
  • com.android.vending.BILLING — Google Play purchases.

No advertising-ID, location, microphone, contacts, SMS or shared-storage permission.

6. Purchases — Google Play Billing and Stripe

6.1 In-app purchases on Android (Google Play)

On the Google Play build, in-app purchases go through Google Play Billing. We do not receive the card number. Google Play parental controls apply. Google policy: policies.google.com/privacy.

6.2 Purchases on the website, or from a build outside Google Play

Payments are processed by Stripe. You enter payment details on a Stripe page (from the website or, outside Play, from the game). Mathéquête never sees the card number. Stripe may send us an email address (to deliver the code) and an optional name for the receipt. Applicable taxes, if any, are calculated by Stripe Tax. Policy: stripe.com/privacy.

License emails are sent through Resend (United States). Policy: resend.com/legal/privacy-policy.

8. Security

Game traffic to our servers and to Cloudflare Pages uses TLS/HTTPS. License codes are signed (HMAC-SHA256) so they can be checked offline. Cloudflare states that D1 is encrypted at rest. As noted in section 3, local profiles are not encrypted at rest.

9. Rights (Law 25, GDPR, COPPA)

You, or the parent / guardian of a child user, may in particular:

  • access the data visible in the game (profiles, licenses, school identifier) and ask for a copy of what we hold on the server (activations, email activation requests);
  • correct profiles and the school identifier in the game, within the limits of locked fields (a locked civil identity may require validation);
  • request deletion of a profile in “Manage profiles”, uninstall the app, or ask us to erase server records tied to your device, activation email or license;
  • object or withdraw consent for optional features (school identifier, Play Games cloud save, support email);
  • be informed, under Law 25, of a confidentiality incident that presents a risk of serious injury.

Contact and Law 25 officer: Jeff Gravel — coresrdi@gmail.com

Target response time: 30 days (or any shorter period required by applicable law).

10. Deleting data and accounts

Mathéquête does not create a child account with a password. Data tied to a person or a device is mainly: local files, server-side license activations and fingerprints, email activation requests, and, where applicable, a Play Games save or a teacher account.

  • On the device: delete the profile or uninstall the app.
  • Web request (recommended, no reinstall needed): use the data deletion request page, or write to coresrdi@gmail.com with the email you used, the license code or type if you know it, and what you want deleted. In the game, starting with the next package (versionCode > 37), the “Delete my data” button in the parent area opens this page after a parental gate.
  • Play Games cloud save: turn the option off in Settings; copies already at Google are managed from the Google account, or with our help.
  • Teacher account (Mathéquête Prof app): a teacher can delete their account from that app (the dedicated function; on the server it calls DELETE /api/prof/me/delete), or use the same request page.

11. Retention

  • On the device: for as long as the app is installed, or until the profile is deleted.
  • License activations: for as long as the license is valid, or until a deletion request or a successful transfer.
  • Manual activation requests: for as long as needed to process them, then according to our support follow-up needs.
  • Technical logs and version checks: traces (possibly including an IP address seen by Cloudflare) may exist in infrastructure logs for a period we do not specify here beyond the host's usual practices and our security needs.
  • Purchase invoices (Stripe): kept as long as applicable tax and accounting rules require (Revenu Québec / Canada Revenue Agency), typically several years.
  • We do not claim a retention period for “synchronised school statistics”, because that upload is not implemented in the game client today.

12. International transfers

Some processors are located outside Quebec and Canada:

  • Cloudflare — global network; data may transit through the United States or other countries. Cloudflare relies on standard contractual clauses and, where applicable, the Data Privacy Framework;
  • Stripe and Resend — processing in the United States, under their policies;
  • Google — distribution, billing and, if enabled, Play Games, under Google's policies.

These uses of foreign providers are communications of personal information outside Quebec within the meaning of Law 25. We limit them to the purposes described in this policy.

13. Changes

A substantial change (a new data category or a new network transfer) will be signalled by the update date at the top of this page, and where appropriate by a notice on mathequete.pages.dev or an email to the address associated with a Stripe purchase. The history is public at github.com/coresrdi/mathequete-privacy.
